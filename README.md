# Xagan6_9 — сайт-портфолио

Личный сайт-портфолио на **Python + Flask** в теме «золото на тёмно-синем».

## Быстрый старт (Windows)

Дважды щёлкните **`start.bat`**: он сам создаст окружение, установит зависимости и откроет сайт
по адресу http://127.0.0.1:5000.

Вручную:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

## Полезные команды

| Команда | Что делает |
|---|---|
| `python run.py` | запуск сайта в режиме разработки |
| `pytest` | проверка, что все страницы открываются |
| `python freeze.py` | сборка статического сайта в папку `build/` |

## Как добавить свой контент

- **Проект** — допишите блок в `content/projects.yaml`.
- **Статью** — создайте `.md` файл в `content/posts/`.
- **Имя, ссылки, навыки** — `config.py`.
- **Цвета** — переменные в начале `app/static/css/style.css`.
