## Почему Flask

Для портфолио не нужна тяжёлая админка и база данных. Flask даёт ровно столько,
сколько нужно: маршруты, шаблоны и статику.

## Контент отдельно от кода

Проекты лежат в `content/projects.yaml`, статьи — в `content/posts/*.md`.
Чтобы добавить проект, не нужно трогать Python:

```yaml
- slug: my-project
  title: Мой проект
  stack: [Python]
```

## Цвета

Вся палитра — в CSS-переменных:

```css
:root {
  --navy-800: #0a1428;
  --gold-500: #d4af37;
}
```

> Поменяй две строчки — и у сайта новая тема.
